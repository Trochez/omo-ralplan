# Examples

This directory contains example usage scenarios for the OMO-Ralplan skill.

## Contents

- `basic-usage.md` - Simple planning examples
- `interactive-mode.md` - Interactive workflow examples
- `deliberate-mode.md` - High-risk task examples
- `advanced-patterns.md` - Advanced usage patterns

## Quick Examples

### Basic Planning

```
$omo-ralplan "Add caching layer to the API"
```

### Interactive Mode

```
$omo-ralplan --interactive "Implement user roles and permissions"
```

### High-Risk Tasks

```
$omo-ralplan --deliberate "Migrate from REST to GraphQL"
```

### With File Reference

```
$omo-ralplan "Refactor authentication in src/auth/"
```

### With Issue Reference

```
$omo-ralplan "Implement feature from #42"
```
